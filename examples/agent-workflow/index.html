A generic multi-agent workflow

This method is platform-independent. It models a reusable process rather than a fixed team, data provider, or domain.

Execution role

Transforms attributable input into a planned, versioned deck. It records source links, assumptions, and open questions.

Independent verification role

Checks claims, citations, layout fit, navigation, responsiveness, and reduced-motion behavior without rewriting the execution record.

Data → Skill → Agent: data provides evidence, a skill states the method, and an agent carries out the work with an auditable handoff.
