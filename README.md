# OneChartLab Slides

**English** | [简体中文](README.zh-CN.md)

> An agent-first system for creating polished HTML presentations. You provide the source material and requirements; the agent plans, generates, previews, and revises the deck.

OneChartLab Slides gives AI agents a defined design system, 16 purpose-built layouts, and the complete dark ZXcharT visual theme. The goal is not to make users hand-author HTML. It is to help agents produce coherent, reusable presentations under consistent structural and visual constraints.

Users work primarily through natural-language instructions. HTML is the delivery format generated by the agent, not a prerequisite for using the system.

## What it solves

General-purpose AI can generate web pages, but presentations often suffer from inconsistent styling, weak hierarchy, uncontrolled information density, and one-off page structures.

OneChartLab Slides provides agents with:

- shared typography, color, spacing, and motion rules;
- 16 layouts for distinct communication goals;
- an editable HTML seed;
- a workflow from content planning through visual verification;
- a browser-ready deliverable that remains editable.

## Compatible agents

Any AI agent that can read and write local files can use the system. An agent that can also preview HTML can verify overflow, aspect ratio, interactions, and readability.

You can give the agent this repository folder, install it as a Skill, or ask it to read `SKILL.md`, `AGENTS.md`, and the theme specification. OneChartLab Slides is not tied to a particular model or agent platform.

## Install the Skill

Install the **complete `onechartlab-slides` folder**. Do not copy only `SKILL.md`: the Skill also needs its template, design rules, layout reference, and scripts. If you use a ZIP uploader, the archive should contain one top-level folder named exactly `onechartlab-slides/`.

### HanaAgent

Ask HanaAgent to install the GitHub repository as a Skill, or select the repository/ZIP in its Skill installer:

```text
Install this Skill: https://github.com/ZXcharT/onechartlab-slides
```

See [docs/platforms/hanaagent.md](docs/platforms/hanaagent.md) for the local-folder alternative.

### Claude

Enable **Code execution and file creation**, then open **Customize → Skills → Add/Create skill → Upload a skill** and upload a correctly structured ZIP containing the `onechartlab-slides/` folder.

### OpenAI Codex

Ask `$skill-installer` to install the GitHub repository, or place the complete folder at:

```text
~/.agents/skills/onechartlab-slides/
```

For a project-only installation, use `.agents/skills/onechartlab-slides/` inside that project. Restart Codex if a newly installed Skill does not appear.

### First call

After installation, describe the desired result normally or invoke the Skill explicitly where the Agent supports it:

```text
Use OneChartLab Slides to turn this report into a 10-slide presentation.
Show me the outline before generating the HTML.
```

## Create a deck with an AI agent

### 1. Load the system instructions

```text
Read SKILL.md, AGENTS.md, and themes/zxchart/design.md in the
OneChartLab Slides repository before creating the presentation.
```

### 2. Provide a production brief

Include the topic, audience, objective, and source material. Add slide count, tone, or visual constraints when relevant.

```text
Create a 12-slide presentation with OneChartLab Slides.
Topic: the AI infrastructure investment cycle
Audience: individual investors
Objective: explain key bottlenecks and validation signals
Sources: use the research documents I provide
Process: show me the slide outline first; after approval, generate the HTML
and cite every material data point.
```

### 3. Approve the outline

The agent maps each communication goal to an appropriate layout. Confirming what each slide should accomplish before generation avoids rebuilding the narrative after visual work is complete.

### 4. Generate and verify

A robust workflow is:

1. read the source material and identify the core conclusions;
2. plan the sequence and select layouts;
3. copy `template.html` into a project;
4. write the titles, body copy, data, and sources;
5. preview the result in a browser;
6. verify claims, links, overflow, and readability;
7. revise from feedback.

See [AGENTS.md](AGENTS.md) and [SKILL.md](SKILL.md) for the full production and verification protocol.

## Do users need to know HTML?

**No.** A typical user communicates with the agent in natural language and reviews the outline and final presentation.

The deliverable is an HTML file that plays in a browser. People who know HTML/CSS may fine-tune the generated file, but manual editing is not the primary workflow.

## Layout system

- **Open and close:** `layout-cover`, `layout-outro`, `layout-closing`
- **Agenda and content structure:** `layout-agenda`, `layout-split`, `layout-detail`, `layout-stack`
- **Data and comparison:** `layout-metrics`, `layout-dashboard`, `layout-bars`, `layout-compare`
- **Narrative and argument:** `layout-quote`, `layout-timeline`, `layout-timeline-3col`, `layout-hook`, `layout-statement`

The agent chooses layouts according to the purpose of each slide; users do not need to memorize these identifiers. See [docs/layouts.md](docs/layouts.md) for detailed guidance.

## Features

- 16 reusable layouts covering openings, agendas, data, comparisons, timelines, arguments, and closing pages
- A single HTML file for the main content, styling, and interactions
- Dark ZXcharT theme with restrained gold emphasis
- Keyboard, touch, and button navigation
- Click-to-focus cards, animated bars, and `prefers-reduced-motion` support
- Platform-neutral instructions without private tools or personal runtime dependencies

## Advanced use: manual scaffolding

This is not the primary workflow. Advanced users can copy `template.html` directly or run a generator to create a project folder.

### macOS / Linux

```sh
sh scripts/new-project.sh "my-deck"
```

### Windows

```powershell
py scripts/new-project.py "my-deck"
```

The generators only create a template copy under `projects/my-deck/`; they do not upload files or connect to an AI service. An agent may invoke them as part of its workflow.

## Browser compatibility

Use a current version of Chrome, Edge, Firefox, or Safari. JavaScript powers navigation and optional interactions. System fonts act as fallbacks when Google Fonts are unavailable.
