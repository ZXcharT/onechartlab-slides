# Layouts

The audited seed contains 16 layout classes. Use only the layouts needed for the story.

| Class | Use |
|---|---|
| `layout-cover` | Opening statement, title, scope |
| `layout-agenda` | Six-part overview |
| `layout-metrics` | Three labeled measures |
| `layout-dashboard` | Six compact status cells |
| `layout-split` | Evidence alongside interpretation |
| `layout-bars` | Ranked values with explicit units |
| `layout-quote` | Attributable quotation |
| `layout-timeline` | Four-step horizontal workflow |
| `layout-detail` | Two-column detail blocks |
| `layout-stack` | Layered system or dependency model |
| `layout-compare` | Criteria-based options table |
| `layout-timeline-3col` | Event, sequence, response alignment |
| `layout-hook` | A concrete framing question |
| `layout-statement` | A concise thesis |
| `layout-outro` | Reflective transition or conclusion |
| `layout-closing` | Final completion screen |

Bar values, dashboard values, quotations, and comparisons are presentation forms, not evidence. Supply source, period, unit, and method whenever a slide makes a factual claim.
