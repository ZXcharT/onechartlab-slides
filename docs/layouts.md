# Layouts

Both audited templates contain the same 16 layout classes in a fixed order. Use only the layouts needed for the story.

- Choose **ZXcharT Briefing** by default for research, strategy, reporting, data, and decision work.
- Choose **ZXcharT Showcase** for launches, proposals, keynotes, and narrative stage work where modular pacing and bounded atmosphere are useful.

Template choice does not change layout identifiers or the content evidence standard.

| Class | Use |
|---|---|
| `layout-cover` | Content-first opening: title, scope, author/date |
| `layout-agenda` | Weighted narrative directory |
| `layout-metrics` | One primary measure with supporting interpretation |
| `layout-dashboard` | Primary status with supporting evidence and ownership |
| `layout-split` | Asymmetric evidence and conclusion |
| `layout-bars` | Ranked values with explicit units |
| `layout-quote` | Attributable quotation |
| `layout-timeline` | Four-step horizontal workflow |
| `layout-detail` | Structured annotation rail |
| `layout-stack` | Layered system or dependency model |
| `layout-compare` | Flat, criteria-based decision table with a labelled narrow-screen scroll region |
| `layout-timeline-3col` | Event, sequence, response alignment |
| `layout-hook` | A concrete framing question |
| `layout-statement` | A concise thesis |
| `layout-outro` | Reflective transition or conclusion |
| `layout-closing` | Final completion screen |

Bar values, dashboard values, quotations, and comparisons are presentation forms, not evidence. Supply source, period, unit, and method whenever a slide makes a factual claim. On narrow screens, preserve readable copy and permit controlled vertical flow rather than silently clipping content.
