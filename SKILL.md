# OneChartLab Slides skill

Use this skill when a user asks for an HTML slide deck, a browser-based presentation, a layout plan, or a reusable slide seed.

## Workflow

1. **Align**: establish audience, goal, delivery medium, accessibility needs, and authoritative source material.
2. **Plan**: map each point to an available layout from `docs/layouts.md`; identify missing evidence and obtain confirmation for a substantive outline.
3. **Generate**: create a new project with a repository-relative or user-specified path; copy `template.html`; retain only required slides.
4. **Preview**: test keyboard and touch navigation, responsive size, contrast, citations, and reduced-motion behavior.
5. **Iterate**: change tokens before rewriting component CSS; keep claims attributable.
6. **Review**: use an independent verifier where available to check facts, links, slide count, and layout fit.
7. **Record**: state what was verified, what remains uncertain, and where the output lives.

Layout inventory: `layout-cover`, `layout-agenda`, `layout-metrics`, `layout-dashboard`, `layout-split`, `layout-bars`, `layout-quote`, `layout-timeline`, `layout-detail`, `layout-stack`, `layout-compare`, `layout-timeline-3col`, `layout-hook`, `layout-statement`, `layout-outro`, `layout-closing`.

Do not assume a named agent, local path, installed data product, or platform-specific command. Do not invent statistics, quotations, images, or testimonials. Use only material with a source and appropriate permission.
